# Lantern Library — landing page

A small neighbourhood library that lends out tools, not books: drills, ladders,
sewing machines. Build a one-page site for it.

## Audience
Residents of the neighbourhood who want to borrow something for a weekend.

## Content
- A headline and one sentence saying what the library lends.
- Three featured items, each with a name and a one-line description.
- Opening hours: Saturday and Sunday, 10:00 to 16:00.
- A sign-up call to action: "Join for free".

## Tone
Warm, practical, plain words.
